# 📚 لغتي الممتعة — كتاب إلكتروني تفاعلي للصف الأول الابتدائي

من إنتاج **صوفيا ويونس** ✨

كتاب تفاعلي كامل بملف واحد (HTML) يعمل على أي جهاز وبدون إنترنت — للمدارس والمعلمين وأولياء الأمور.

## 🎯 المحتوى (٣٨ مهارة)

- **حروف وحركات**: الحروف الهجائية الـ٢٨، الحركات القصيرة، المدود، التنوين، الساكن، الشدة (كل وحدة لحالها)
- **✍️ اكتب الحرف**: تتبع الحرف بالإصبع أو الفأرة مع تحقق ذكي
- **🔊 اسمع واختر / 🖼️ الحرف الأول / 🧩 ركّب الكلمة**
- **مهارات تفكير**: ما المختلف · أكمل النمط · عدّ واختر · روابط الأعداد (سنغافورة) · صنّف الأشياء · رتّب القصة · السبب والنتيجة · لاحظ الفرق (كومون) · وصّل · الشيء الناقص · لعبة الذاكرة
- **معرفة عامة (اسمع واختر بالصورة)**: الألوان، الحيوانات، الأشكال، الفواكه، المواصلات، الأرقام، أجزاء الجسم، الطقس، الأدوات المدرسية، أفراد الأسرة
- **English**: Letters (A-Z)، Listen & Choose، Fruit Basket، Animals
- **ذكاءات إضافية**: التعرف على المشاعر (اجتماعي/عاطفي) · أكمل الإيقاع (موسيقي)
- **👤 ملفات شخصية متعددة**: كل طفل يختار اسمه وشكله، وتقدمه محفوظ لحاله عن باقي إخوته
- **🔥 سلسلة يومية** لطيفة بدون ضغط
- **🎚️ اختيار صوت النطق** العربي من بين الأصوات المتاحة بالجهاز
- **🏆 الاختبار الختامي + 🎖️ شهادة تفوق + 📋 تقرير معلم** قابلين للطباعة
- **⭐ نظام تحفيز**: ١١٤ نجمة وشريط تقدم، يُحفظ تلقائياً لكل طفل على حدة

## 🚀 طريقة الاستخدام

افتح ملف `لغتي_الممتعة_كتاب_تفاعلي.html` بأي متصفح (ننصح بكروم أو إيدج). لا يحتاج تثبيت ولا إنترنت.

## 🎙️ ترقية الصوت بتسجيلات بشرية

الكتاب يستخدم القارئ الآلي للمتصفح، ويدعم استبداله بتسجيلات بشرية تلقائياً:

1. أنشئ مجلداً باسم `audio` بجانب ملف الكتاب
2. ضع فيه ملفات `mp3` بالأسماء: `letter_0` إلى `letter_27` (أصوات الحروف بترتيب الهجائية)، و`word_0` إلى `word_27` (الكلمات)
3. متى وُجد الملف يُشغَّل تلقائياً، وإلا يعود الكتاب للقارئ الآلي

## 🛠️ تقنياً

ملف واحد: HTML + CSS + JavaScript بدون أي مكتبات خارجية. يُختبر بمحاكاة متصفح كاملة (Node + DOM وهمي) تغطي كل مسارات الكتاب قبل كل تحديث.
