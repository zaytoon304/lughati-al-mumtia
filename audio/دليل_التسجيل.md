# دليل تسجيل صوت الطفل (تحديث: باقي ٩ كلمات بس)

خبر جيد: كل الحروف الـ٢٨ و١٩ كلمة منهم صارت بصوت طفل حقيقي تلقائياً (راجع `CREDITS_LETTERS.md`). باقي ٩ كلمات بس لو حبيت صوت صوفيا أو يونس فيها بالذات.

## خطوات التسجيل
1. افتح تطبيق "المذكرات الصوتية" (Voice Memos) أو أي تطبيق تسجيل
2. خلّي صوفيا أو يونس يقول كل كلمة بصوت واضح وهادئ
3. صدّر كل تسجيل mp3 (أو m4a) بالاسم المكتوب بالجدول بالظبط
4. حطهم بمجلد `audio` جنب ملف الكتاب — نفس المكان اللي فيه باقي الملفات
5. الكتاب هيستخدمهم تلقائياً بدون أي تعديل على الكود

هذا اختياري تماماً — الكتاب شغال ممتاز بدونهم (بيستخدم القارئ الآلي لهالتسعة بس).
